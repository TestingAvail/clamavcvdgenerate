# ClamAV CVD Generator

Утилита и автоматизация для генерации и упаковки баз данных (`.cvd` / `.cld`) под ClamAV.

## Назначение
Позволяет собирать кастомные сигнатуры и базы данных для антивирусного сканера ClamAV в автоматизированном режиме через GitHub Actions.

## Применение
Обеспечивает актуальность локальных баз сигнатур без ручного вмешательства и долгой возни с компиляцией баз.
